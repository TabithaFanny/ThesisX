## Page 01｜工作台 / 首页

生成 16:9 横版 ThesisX 工作台首页界面。浅色学术软件风格，顶部有产品名 ThesisX、搜索框、用户头像与新建论文按钮；左侧竖向导航包含我的论文、文献管理、数据与图表、写作技能库、投稿与回复、设置中心；中间区域展示问候语、3 个项目进度卡片、最近编辑文件列表、待办事项；卡片使用白色底、细蓝灰边框、柔和阴影，强调色为清爽蓝与少量紫色。界面信息密度适中，留白充分，不要使用花哨插画。

## Page 02｜编辑器（主要交互页）

生成 16:9 横版 ThesisX WYSIWYG 论文编辑器界面。顶部为文档工具栏，包含产品名、文档下拉、保存状态、撤销重做、导出、AI 按钮、设置入口；左侧为论文大纲树，展示章节层级并高亮当前小节；中央为正文编辑区，显示论文标题“1.1 研究背景与意义”、多段正文占位、AI 内联提示卡和图片/图表占位；右侧为实时预览区，展示当前章节渲染效果。整体风格为浅色学术工具界面，蓝色强调，细线卡片。

## Page 03｜AI 对话 / 助手

生成 16:9 横版 Agent 对话主控页。左侧为对话历史与 Agent 列表，包含论文写手、审稿人、润色师、文献研究员等；中间为对话流，显示用户指令、AI 回复、引用上下文卡片、skill 调用标签；右侧为项目上下文面板，展示当前论文题目、已选章节、可用 Skill、当前任务产物和 Review 状态；底部为输入框，支持 @文献、#章节、/skill 命令。界面应体现专业研究工作台感。

## Page 04｜文献管理

生成 16:9 横版文献管理页面。左侧为文献库分类与标签过滤，包括全部文献、我的收藏、待核查、已验证、按主题分类；顶部搜索框可搜索标题、作者、关键词、DOI；右上有导入文献、连接 Zotero、本地文件夹按钮；主区域为文献表格，列出标题、作者、年份、来源、DOI、标签、解析状态、文献评分；右侧可显示选中文献详情卡，包含摘要、引用格式、原文路径和评分维度。

## Page 05｜数据与图表

生成 16:9 横版数据与图表管理页面。左侧为数据集分类：问卷数据、实验数据、分析结果、图表资产；主区域上半部分为数据文件表格，显示文件名、类型、大小、更新时间、分析状态；下半部分为图表缩略图区，包含柱状图、折线图、饼图、热力图、回归图等卡片；右上有“新建图表”“上传数据”“生成论文图表”按钮。整体为干净学术数据工作台。

## Page 06｜写作技能库

生成 16:9 横版写作技能库页面。左侧为技能分类：全部技能、论文写作、逻辑审查、理论审查、证据审查、润色降痕、图表标题、投稿回复；中间为技能卡片矩阵，每张卡包含技能名称、用途说明、适用语言、调用次数、评分、启用开关；右侧为选中技能详情，包括 system prompt 摘要、输入 schema、输出 schema、适用 Agent、风险规则。强调可配置与专业感。

## Page 07｜版本历史

生成 16:9 横版版本历史与 Diff 页面。左侧为版本时间线，显示 v12 最新版本、v11 审稿修改、v10 草稿、v9 引用补充等；中间为差异对比区域，红色块展示删除内容，绿色块展示新增内容，蓝色注释显示修改原因；右侧为版本信息，包括修改 Agent、调用 Skill、审稿结论、费用、时间、可回滚按钮。界面要清晰表达论文版本控制。

## Page 08｜协作空间

生成 16:9 横版协作空间页面。左侧为讨论流，展示导师、合作者、AI Agent 的消息，含头像、时间、引用段落；中间为任务看板，分为待处理、进行中、待审稿、已完成；右侧为成员与权限列表，显示 Owner、Editor、Reviewer、Viewer。页面应体现论文协作、任务分派和审稿沟通。

## Page 09｜投稿与回复

生成 16:9 横版投稿与回复管理页面。顶部有投稿状态概览卡：待投稿、审稿中、Rebuttal、已接收、被拒；主区域为期刊/会议投稿表格，列出名称、状态、投稿时间、截止时间、操作；右侧为审稿意见与回复计划面板，可显示 reviewer comment 分类、response strategy、需要补实验/补文献/改写的任务。界面专业、克制。

## Page 10｜设置中心

生成 16:9 横版设置中心页面。左侧为设置导航：个人信息、偏好设置、模型设置、接口配置、文献库连接、OCR 设置、RAG 设置、隐私安全；主区域展示模型设置表单，包括默认模型、备用模型、API Base URL、温度、语言、预算上限；下方展示 Connector 配置：Zotero、本地文件夹、OpenAlex、CrossRef、Semantic Scholar、Unpaywall、OCR 引擎。整体布局清晰，像专业桌面软件设置页。
